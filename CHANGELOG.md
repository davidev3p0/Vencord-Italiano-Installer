# Changelog

Tutte le modifiche rilevanti al progetto vengono documentate qui.

## [1.0.0]

Prima release pubblica dell'installer autonomo.

### Aggiunto

- rilevamento Discord Stable, Canary e PTB;
- installazione e aggiornamento di Vencord Italiano;
- riparazione dell'installazione;
- disinstallazione con ripristino dell'originale `app.asar`;
- download dei runtime dalle release GitHub di Vencord Italiano;
- verifica SHA-256 degli asset;
- backup e rollback nelle operazioni di patch;
- CI con `gofmt`, `go vet` e `go test`;
- build Windows tramite GitHub Actions;
- checksum pubblico e GitHub Artifact Attestation;
- policy pubbliche di sicurezza, privacy e code signing.
