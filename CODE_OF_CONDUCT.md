# Code of Conduct

Vencord Italiano Installer vuole mantenere uno spazio tecnico collaborativo e rispettoso.

Sono richiesti:

- rispetto verso utenti e contributori;
- discussioni tecniche in buona fede;
- niente molestie, minacce o attacchi personali;
- niente spam o pubblicazione intenzionale di dati sensibili;
- segnalazioni di sicurezza gestite in modo responsabile.

Comportamenti incompatibili con queste regole possono portare alla moderazione di issue, commenti o contributi.

Per questioni di sicurezza consulta [SECURITY.md](SECURITY.md).
