# Privacy policy

Vencord Italiano Installer does not contain advertising, analytics or project-specific telemetry.

The installer contacts GitHub only to:

- read the latest public release metadata from davidev3p0/Vencord-Italiano;
- download the four Vencord Italiano runtime files required by the installation.

The installer does not upload Discord credentials, account data, messages, settings or personal files.

Vencord Italiano itself has its own functionality and optional settings. This installer does not change the user's Vencord settings except by installing or repairing the runtime files.
