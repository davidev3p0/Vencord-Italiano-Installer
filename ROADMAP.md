# Roadmap

La roadmap è volutamente conservativa: stabilità e trasparenza vengono prima dell'aggiunta di nuove funzioni.

## Disponibile

- [x] Installer Windows autonomo in Go
- [x] Discord Stable
- [x] Discord Canary
- [x] Discord PTB
- [x] Installazione / aggiornamento
- [x] Riparazione
- [x] Disinstallazione con ripristino
- [x] Download dalle release di Vencord Italiano
- [x] Verifica SHA-256 degli asset
- [x] GitHub Actions CI
- [x] GitHub Artifact Attestation
- [x] Release pubbliche
- [x] Policy di privacy, sicurezza e code signing

## Prossimi obiettivi

- [ ] aumentare i test reali su Stable, Canary e PTB
- [ ] ampliare i test automatici di rollback e gestione errori
- [ ] migliorare i messaggi diagnostici senza aumentare la complessità
- [ ] ottenere code signing Authenticode pubblicamente attendibile quando il progetto sarà idoneo
- [ ] documentare eventuali incompatibilità note
- [ ] valutare una UI grafica minimale solo se non peggiora stabilità e verificabilità

Le priorità possono cambiare in base ai bug reali e ai feedback della comunità.
