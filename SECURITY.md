# Security policy

## Supported version

Only the latest public release of Vencord Italiano Installer is supported.

## Reporting

Please report security-sensitive issues privately to the repository maintainer. Do not publish exploit details in a public issue before a fix is available.

Ordinary bugs and compatibility problems may be reported through GitHub Issues.

## Release integrity

Official release binaries are produced from this repository through GitHub Actions. Release artifacts use SHA-256 and GitHub build provenance. Authenticode signing is intended to be performed through SignPath according to CODE_SIGNING_POLICY.md.
