# Support

Per problemi con Vencord Italiano Installer usa le GitHub Issues di questo repository.

Quando segnali un problema indica:

- versione dell'installer;
- Windows 10/11 e relativa versione;
- Discord Stable, Canary o PTB;
- operazione scelta: installazione, riparazione o disinstallazione;
- messaggio di errore completo;
- passaggi per riprodurre il problema.

Non includere token Discord, password, cookie, credenziali o altri dati sensibili.

Per problemi relativi alla traduzione, ai plugin o all'updater interno di Vencord Italiano, usa il repository principale:
https://github.com/davidev3p0/Vencord-Italiano
